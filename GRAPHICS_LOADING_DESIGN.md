# Graphics loading and quality transitions

The renderer is created before artwork decoding so KTX2Loader detects support on the exact context that draws the game. WorldView accepts that renderer rather than creating another context. A model portrait may create its separate renderer using the same power preference. These API choices follow the [Three.js KTX2Loader documentation](https://threejs.org/docs/pages/KTX2Loader.html) and [WebGLRenderer compilation documentation](https://threejs.org/docs/pages/WebGLRenderer.html#compileAsync).

Fourteen UASTC color/ARM maps retain 1024 × 1024 pixels and eleven mip levels; original normal maps retain their direction detail. The accepted encoder setting is gltfpack 1.3 UASTC quality 3 with one worker thread. Encoded/source SHA-256, dimensions and transfer functions are checked by tests. Color uses sRGB and ARM/normal data remains linear. Texture residency is keyed by role/kind, shares pending loads, retries failures and evicts only completed unused maps. Live scene and portrait material/uniform references pin textures. Terrain detail flags and samplers clear when lowering quality. Completed High/Balanced/Low profiles keep 21/17/7 maps respectively; 14/10/7 use compression on a supported GPU.

The fourteen files total 13,629,106 bytes, 4,997,845 bytes more than their original JPEGs. Their compressed mip payload is 19,573,792 bytes at High versus 78,293,656 bytes for equivalent full RGBA mip chains. This excludes original normals, render/shadow targets, other textures and geometry; it is not a measurement of total device memory. Both formats stay bundled for recovery, so offline download/storage grows. The earlier quality-8 prototype totalled 16,083,116 bytes and was never published.

Pixel comparisons render each original and compressed map at full resolution. All fourteen retain the established PSNR ≥ 35 dB and 95th-percentile channel error ≤ 10/255 gates. ASTC has minimum 36.10 dB and BPTC 36.08 dB; both have a maximum 95th-percentile error of 8/255. These are software-GPU comparisons, not a physical-device matrix. Original source geometry and JPEG normal files remain unchanged.

During an upgrade the old battlefield continues rendering while art loads. A downgrade releases oversized renderer/shadow targets early. Scene rebuilding then holds field rendering, shows Updating graphics, and pauses local simulation updates while lightweight independent material proxies prepare shader programs. Proxies preserve material callbacks and instancing flags without copying circular gameplay metadata. Program references release after a live field frame. If optional asynchronous compilation fails, the rebuilt preset renders through ordinary compilation. Decoding failures restore previous renderer targets and keep the existing scene; unexpected exceptions inside scene replacement are not yet transactional. Multiplayer's authoritative server continues independently during client graphics changes.

Without WebGL 2 the first boot displays an accessible focused Reload game dialog, disables the background landing controls and makes no GLB/JPEG/KTX2/WASM requests or service-worker registration attempts. It preserves the saved manual preference. Successful production boots still prepare the complete offline cache, including all three catalogues, 21 original maps, 14 compressed maps and both decoder files. Offline verification reloads without network access, starts a battle, switches to Balanced from cached assets, holds local time for 24 live UI frames during preparation, and verifies real rendering and simulation resume.

Verification uses 328 serial Node tests and production 1792122713315. Repeated preset switches were rendered at 800 × 480 under software graphics; the landscape-touch image/fallback cases use 640 × 360. Offline play uses 960 × 640. Startup failure covers 960 × 640 desktop and 640 × 360 actual emulated-touch contexts. These checks establish functional behavior and inspected visuals, not native phone input, sustained FPS, universal smoothness or whole-game release readiness. The initial caching/decoder cost and JS bundle warnings remain visible in the build reports. The prior software missing-glyph artifact was not reproduced in current inspected High/Balanced/offline images, but its original cause remains unknown.

# Material sources

These texture sets are by Poly Haven contributors and are distributed under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). See the [Poly Haven license](https://polyhaven.com/license).

- [Leafy Grass](https://polyhaven.com/a/leafy_grass) — Charlotte Baglioni; original 1k diffuse, OpenGL normal, and packed AO/roughness/metallic JPEG maps.
- [Medieval Blocks 05](https://polyhaven.com/a/medieval_blocks_05) — Rob Tuytel; original 1k diffuse, OpenGL normal, and packed AO/roughness/metallic JPEG maps.
- [Old Wood Floor](https://polyhaven.com/a/old_wood_floor) — Guillaume Monsergent; original 1k diffuse, OpenGL normal, and packed AO/roughness/metallic JPEG maps.
- [Painted Plaster Wall](https://polyhaven.com/a/painted_plaster_wall) — Amal Kumar; original 1k diffuse, OpenGL normal, and packed AO/roughness/metallic JPEG maps.
- [Brown Mud](https://polyhaven.com/a/brown_mud) — Rob Tuytel; original 1k diffuse, OpenGL normal, and packed AO/roughness/metallic JPEG maps.
- [Rocky Terrain 02](https://polyhaven.com/a/rocky_terrain_02) — Amal Kumar; original 1k diffuse, OpenGL normal, and packed AO/roughness/metallic JPEG maps.
- [Rock 01](https://polyhaven.com/a/rock_01) — Rob Tuytel; original 1k diffuse, OpenGL normal, and packed AO/roughness/metallic JPEG maps.

Original downloaded files are verified against the source API file size and MD5. Runtime assets are bundled locally; the game does not call Poly Haven services.
